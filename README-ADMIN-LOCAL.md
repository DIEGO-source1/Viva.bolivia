# Administración inicial

- Crear la cuenta única: `backend/ADMIN-CREAR-CUENTA.md` (`npm run admin:create`).
- Cambiar la contraseña de una cuenta admin existente: `backend/ADMIN-RESTABLECER-CUENTA.md` (`npm run admin:reset-password`).
- Mantener las credenciales solo en `backend/.env`; nunca subir ese archivo a GitHub.
- La migración de identidad debe aplicarse una sola vez, después de un respaldo de Neon.
